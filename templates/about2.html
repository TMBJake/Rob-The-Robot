About the Smart Robot Car

This project is an IoT-enabled smart robot car built for the course 420-N55: IoT – Design and Prototyping of Connected Devices. The goal is to design a car that can be controlled remotely through a Flask web app and Adafruit IO, and that can also drive itself using infrared line-tracking and ultrasonic obstacle-avoidance modes.

The robot sends live sensor data to Adafruit IO and stores historical data in a Neon PostgreSQL database. This allows us to visualize both real-time and historical behaviour of the robot from the dashboard.

Hardware & Sensors

Core Platform

  • Raspberry Pi controlling all logic and networking
  • Motor driver + DC motors for movement
  • Servo motor for camera or sensor rotation (depending on setup)

Sensors

  • Infrared line-following sensors
  • Ultrasonic distance sensor for obstacles
  • Voltage / battery monitoring via Adafruit IO

Software & Data Flow

The Raspberry Pi continuously reads all sensors and sends values to Adafruit IO using MQTT and HTTP. Every reading is saved locally in SQLite, and when internet is available the Pi syncs the local data to a Neon cloud database.

This Flask + Chart.js dashboard includes:

  • Home – overview and quick access to features
  • About – project description (this page)
  • Sensor Data – fetches historical data from the Neon DB
  • Directional Controls – manual driving using Adafruit IO commands
  • Automated Command Control – switch between IR tracking, ultrasonic mode, or stop
